# V1 prototype archive

These documents, deployment helpers, and SQL patches describe the retired Supabase prototype. They are preserved as migration evidence. Do not apply them to V2: some intentionally granted anonymous write access during prototyping.

Start with the [current README](../../README.md), [V2 architecture](../v2/architecture.md), and [migration guide](../v2/migration.md). Legacy page and puzzle code remains isolated behind the disabled-by-default legacy route group while content is migrated.
